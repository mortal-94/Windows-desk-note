# DeskNote v0.2.6

编辑笔记后点击桌面或其它应用，笔记会先保存，再自动回到桌面嵌入状态。通过快捷键进入编辑后也具有相同行为。

## 改进

- 使用窗口失去激活事件触发返回，不增加轮询或全局鼠标钩子。
- 右键菜单、设置对话框操作期间延后返回；操作结束后重新检查焦点。
- 返回桌面时关闭搜索不会重新聚焦编辑器，避免抢走其它应用的输入焦点。
- 保存前处理待完成的 TODO 输入规范化，拦截重复切换；保存失败时保留可编辑窗口和内存内容。

## 下载与升级

- **DeskNote-v0.2.6-win-x64.zip**：推荐的 Windows x64 自包含便携版，内含 .NET 运行时。
- **DeskNote-v0.2.6-win-x64-framework-dependent.zip**：精简版，需要 .NET 10 Desktop Runtime x64。
- **SHA256SUMS.txt**：上述 ZIP 的 SHA-256 校验值。

完整解压 ZIP 后运行 `DeskNote.exe`。升级前在旧版笔记中点击“退出”，确认保存成功，再启动新版。用户笔记、设置和历史备份位于 `%LOCALAPPDATA%\WindowsDeskNote`，升级时请保留该目录。发行包不携带个人数据。

## 验证与边界

格式检查通过；Release 构建 0 警告、0 错误；35 项自动化测试通过（核心 29 项、WPF STA 回归 6 项）。测试全部使用隔离临时目录。

WPF 回归覆盖强制保存和旧内容备份、设置期间延后、菜单关闭复查、切换保护、待处理 TODO 输入规范化及保存失败后的内容保留。
